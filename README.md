# Castaway

A 3D survival game built with Three.js in a 10-minute challenge: you are the lone survivor of a plane crash, stranded on a tropical island.

Open `index.html` in a browser.

- WASD move, Shift sprint, E pick up / use, drag to look, scroll to zoom
- Collect 6 driftwood, eat coconuts, raid supply crates for water
- Build and light the signal fire at the stone ring on the beach, then survive until the ship arrives
